# Public portfolio content review

This directory is the publication gate for NewBoy Work and Research content.

## Status values

- `draft`: being written; not eligible for migration.
- `needs-review`: extracted and assessed, but one or more public claims need a decision or evidence.
- `approved`: Yanfei has approved the exact public scope and unresolved claims have been removed or resolved.
- `withdrawn`: must not be published.

Only `approved` entries may be copied into production content data. Evidence notes remain repository documentation and are not rendered in the public UI.

## Source order

1. Yanfei's explicit confirmation.
2. The Career Workspace verified facts and Story Bank.
3. Reviewable source files under `01Datesource/`.
4. Existing portfolio copy, which is a draft rather than evidence.

When sources disagree, publication stops until the conflict is resolved. Historical website copy never overrides a corrected fact.

## Release process

1. Extract every metric, named client, outcome and strong attribution.
2. Mark each claim as confirmed, supported, unresolved, overclaim risk or withdrawn.
3. Rewrite or remove anything that is not publishable.
4. Obtain Yanfei's approval for the resulting scope.
5. Mark the entry `approved` and record the approval date.
6. Migrate the approved copy into NewBoy and verify both languages.
